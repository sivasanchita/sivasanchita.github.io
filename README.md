# sivasanchita.github.io
This is who I am – my thoughts, beliefs, values, lived experience and training, all in one place.

Live site: https://sivasanchita.github.io

## How it's built

A [Jekyll](https://jekyllrb.com) site, built and hosted by GitHub Pages.

- Work happens on the `dev` branch; `main` is the live site.
- Project rules for collaborators and Claude Code are in [CLAUDE.md](CLAUDE.md).

## Preview locally

```sh
bundle install              # first time only
bundle exec jekyll serve    # then open http://localhost:4000
```

## Where things live

- `_config.yml` — site settings, navigation, contact links
- `_layouts/`, `_includes/` — page templates, header, footer
- `assets/css/style.css` — all styling; colours are at the top
- `index.html` — home / About
- `pages/` — Journey, Work & impact, Writing, Skills, Things I love
- `_posts/` — published writing (`YYYY-MM-DD-title.md`)
